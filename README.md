# Vraxis Drop V2

A fresh implementation of the accountless, temporary transfer website. The original `vraxis-` repository is unchanged.

## Milestone 1
- Text and file transfers with one-time pickup codes
- Expiring drops
- Mobile-first interface inspired by V1's ivory, ember, Instrument Serif and glass navigation

## Run locally
```bash
pip install -r requirements.txt
python app.py
```

**Status:** early prototype; do not deploy publicly without rate limiting, persistent storage, and security review.
