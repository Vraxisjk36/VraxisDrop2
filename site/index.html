Good to know

Questions, answered.

Do I need to create an account?

No. You can create and retrieve temporary drops without registering.

How long does a drop stay available?

Choose one hour or 24 hours. A drop also becomes unavailable immediately after its first successful retrieval.

What can I send?

Text, links, and files up to 9 MB for encrypted uploads. If you select a file, the file is sent instead of the text in the message field.

Is this end-to-end encrypted?

New Quick Drops are encrypted in your browser using AES-256-GCM before upload. The key is contained in the full pickup link, not sent to Supabase. Older drops may be unencrypted. This feature has not yet undergone independent security review.

What happens after a file expires?

The pickup code stops working. Background cleanup of expired stored files is still being developed.

Can I retrieve a drop twice?

No. A code is designed for a single successful claim. Make a new drop if you need to share it again.
